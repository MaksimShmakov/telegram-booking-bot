## 1. Цель задачи

Автоматизировать ежедневный сбор аналитики по TG-рассылкам школы из
AmoCRM. Сейчас цифры снимаются руками с дашборда по фильтру даты — нужно
получать их автоматически, по фильтру **«бот × дата»**, в составе:
**кол-во лидов / кол-во неликвида / кол-во оплат ОП**. Логика фильтров —
идентична текущему дашборду, чтобы цифры сходились с ручным сбором.

## 2. Описание задачи

**Контекст.** В школе ежедневно вручную снимаются три метрики по
TG-рассылкам: открывается дашборд аналитики в AmoCRM, ставится фильтр по
дате, выписываются «лиды», «неликвид» и «оплаты ОП», переносятся в
сводку. Делать это вручную каждый день неудобно и подвержено ошибкам —
хочется получать те же числа автоматически.

**Что нужно получить на выходе.** Автоматическую ежедневную выгрузку
тройки чисел `(лиды, неликвид, оплаты ОП)` по двум разрезам:

- **дата** — любой прошедший день;
- **бот** — конкретный TG-бот Salebot из справочника школы.

Формат итоговой выгрузки — на усмотрение отдела аналитики (Google Sheets,
внутренний отчёт, дашборд с экспортом — что у вас уже отлажено).

**Эталон.** Существующий дашборд аналитики, с которого снимаются цифры
сейчас. Логика фильтров (этап воронки, теги, статусы, ответственные)
должна совпадать 1-в-1.
