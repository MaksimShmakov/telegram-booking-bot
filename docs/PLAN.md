# План разработки

## Согласованные вводные

| Что | Решение |
|---|---|
| ВК-каналы | 15+ групп через **Senler API** |
| ВК «заявка» | клик по кнопке **«Узнать больше»** в рассылке |
| TG-каналы | **4 проекта Salebot**, N ботов в каждом |
| TG: метрики рассылок | Salebot API, вкладка «Рассылки» |
| TG: заявки | **Postgres AmoCRM напрямую** (не через DataLens, не через API Amo) |
| Сегментация | классы 9/10/11 определяются **по названию рассылки** |
| Хостинг | тот же сервер, что и существующий бот школы |
| Запись данных | **Google Sheets** (gspread + service account) |
| Расписание | каждый день 07:00 Мск, APScheduler внутри процесса |
| Бэкфилл | не требуется |

### Этап 1 — ВК через Senler (2–3 дня)

- `senler_client.py`: список рассылок за дату, метрики, клики по кнопкам.
- Для каждой рассылки: ищем кнопку с текстом «Узнать больше» → её clicks = заявки. Если кнопки нет — warning в лог.
- Прогон на 2–3 группах, сверка с ручным подсчётом Гриши.

### Этап 2 — TG: Salebot + AmoCRM (3–4 дня)

- `salebot_client.py`: обход 4 проектов × N ботов, рассылки за дату, размеры аудитории.
- `amo_db.py`: SQL-выгрузка сделок за дату по фильтру источник/тег.
- Связка рассылка ↔ сделки по UTM-метке или тегу (схема — из Этапа 0).
- Сверка с DataLens.

### Этап 3 — классы и нормализация (1–2 дня)

- `classes.py`: regex + словарь исключений.
- Общая рассылка (без классов в названии) → одна строка «9–11».
- Адресная (один класс) → одна строка с этим классом.
- Лог несопоставленных названий.

### Этап 4 — Google Sheets (1 день)

- `sheets.py`: append с ключом `(дата, платформа, канал, mailing_id)` → идемпотентность.
- Листы: `ВК-рассылки`, `TG-рассылки`, `Сырые`. Лист `Сводка` — формулами в самой таблице.

### Этап 5 — планировщик (1 день)

- APScheduler, cron 07:00 Мск.
- Telegram-алерт админу при падении / частичных данных.
- Ретраи с экспоненциальным бэкоффом на сетевые ошибки.

### Этап 6 — сверка (1–2 дня)

- 5–7 дней параллельно с ручным сбором Гриши.
- Чиним расхождения. Допуск: ~±2% по доставленным.

### Этап 7 — документация (0.5 дня)

- README: запуск, ключи, добавление канала/бота, что считается «заявкой», известные ограничения.
